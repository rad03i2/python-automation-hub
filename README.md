# Python Automation Hub

A collection of useful Python automation scripts focused on local productivity, files, reports, and repeatable workflows.

## Tools

- Bulk file rename preview
- Folder organizer
- CSV report builder
- Simple backup checker

## Stack

`Python` · `Automation` · `CLI` · `Files`

## Run

```bash
python automations/bulk_rename_preview.py ./samples
```
